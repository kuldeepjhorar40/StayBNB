# 🌍 Wanderlust-Airbnb

Discover stays. Share experiences.

## 🚀 About
Wanderlust-Airbnb is a full-stack web application where users can explore, create, and review property listings. It is inspired by Airbnb and built with a focus on clean architecture and user experience.

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- Bootstrap / CSS

## ✨ Features
- User authentication (signup/login)
- Create, edit, delete listings
- Add and manage reviews
- Flash messages & error handling
- MVC architecture

## 📂 Project Structure
- `models/` – database schemas
- `routes/` – route handling
- `controllers/` – business logic
- `views/` – frontend (EJS templates)

## ⚙️ Setup Instructions
```bash
git clone https://github.com/nikhil7100/Wanderlust-Airbnb.git
cd Wanderlust-Airbnb
npm install

## 🔐 Environment Variables

Create a `.env` file in the root directory and add:

CLOUD_API_KEY=your_key  
CLOUD_API_SECRET=your_secret  
CLOUD_NAME=your_name  
SECRET=your_secret  

## ▶️ Run the App

```bash
npm start
